# เทรนตัวตรวจจับลูกขนไก่เบา ๆ (YOLO) โดยใช้ TrackNet เป็นครู

เป้าหมาย: ได้โมเดลที่เบากว่า TrackNet (352 ms/ครั้งบน GPU มือถือ) เพื่อไปสู่กล้องสด
วิธี: ให้ TrackNet ติดป้ายลูกบนคลิปสนามของคุณเอง -> เทรน YOLO ขนาดเล็กจากป้ายนั้น

## ไฟล์
- `MDSportLive_yolo_shuttle.ipynb`  โน้ตบุ๊ก Colab (สร้างจาก `autolabel.py` + `train.py` ด้วย `build_notebook.py`)
- `autolabel.py`  ติดป้ายอัตโนมัติ + กรอง + สร้างชุดข้อมูล YOLO + แผ่นภาพตรวจ
- `train.py`  เทรน, ส่งออก ONNX/TFLite, ดูผลทำนาย
- `selftest.py`  ทดสอบตรรกะด้วยวิดีโอสังเคราะห์ (`python tools/yolo/selftest.py`)

## ขั้นตอนใช้งาน (ทำจากมือถือได้)
1. **ไฟล์ครู:** GitHub -> repo -> Actions -> รันล่าสุดที่สำเร็จ -> ดาวน์โหลด artifact `tracknet-tflite` แตก zip ได้ `tracknet.tflite`
2. **Google Drive:** สร้างโฟลเดอร์ `shuttle` อัปโหลด `tracknet.tflite` และสร้างโฟลเดอร์ย่อย `videos` ใส่คลิปสนาม 3–5 คลิป (.mp4 แนวนอน)
   - ใช้คลิปจากสนามและกล้องที่จะใช้จริง หลากหลายแสง/ช่วงเวลา
   - ยิ่งเป็นคลิปจากกล้องดิบ (ไม่มีโอเวอร์เลย์สกอร์) ยิ่งตรงกับตอนใช้สด
3. **Colab:** เปิดไฟล์ `.ipynb` ใน Colab (อัปโหลดไว้ Drive แล้วเปิด หรือ File -> Upload notebook) เลือกรันไทม์ **T4 GPU**
4. **รันทีละช่องตามลำดับ:** ติดตั้ง -> เชื่อม Drive -> เขียนสคริปต์ -> ติดป้าย (รอบแรกใช้ `max_frames=600`)
5. **ตรวจแผ่นภาพ 3 แผ่น** ถ้ากรอบแดงไม่คร่อมลูกจริงเกินครึ่ง อย่าเทรน ปรับ `thr` / `masks` / `static_frac` แล้วรันช่องติดป้ายซ้ำ (มีแคช รอบสองเร็ว)
6. พอป้ายดีแล้ว ตั้ง `max_frames=None` เพื่อใช้ทั้งคลิป แล้วเทรน -> ดูภาพทำนาย -> ส่งออก
7. ไฟล์ผลลัพธ์อยู่ใน `MyDrive/shuttle/model_out/` ส่งกลับมาให้ Claude เพื่อนำเข้าแอปและวัดความเร็วบนมือถือจริง

## ข้อจำกัดที่ควรรู้
- ป้ายมาจาก TrackNet ซึ่งผิดได้ ตัวเลข precision/recall หลังเทรนวัดแค่ "ตรงกับป้ายครู" ไม่ใช่ความแม่นจริง ดูจากภาพทำนายและทดสอบบนมือถือ
- ลูกที่บินผ่านโซนกราฟิกที่ปิดไว้จะไม่ถูกติดป้าย ภาพลบจึงเว้นห่างจากการตรวจจับ 30 เฟรม และมีแผ่นตรวจภาพลบให้ดู
- ตัวเลข "ภาพบวกอย่างน้อย ~300" เป็นเกณฑ์คร่าว ๆ ไม่ใช่ค่าที่พิสูจน์แล้ว
- สคริปต์ส่วนที่ใช้ TensorFlow/ultralytics ยังไม่ได้รันจริง (ทดสอบแค่ตรรกะด้วยครูจำลอง) รอบแรกอาจต้องแก้เล็กน้อย
- ส่งออก TFLite จาก ultralytics บางรุ่นล้มเหลวได้ ถ้าล้มจะยังได้ ONNX และ `best.pt`
